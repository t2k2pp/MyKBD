1. 音を鳴らす準備 (クイックスタート)

  1. オーディオの有効化: ブラウザの仕様により初回は無音状態です。画面右上に表示される 🔊 ENABLE AUDIO ボタンをクリック、または鍵盤・パッドを1回クリックするとオーディオエンジンが起動します。
  2. 音量バランスの確認: 最上段の VOL スライダーが適切な音量になっているか確認します（推奨初期値: 80〜85）。
  3. 出力方式の切替 (SPK / LINE): 上部バー左側のスピーカーマークをクリックすると、2.5インチ小型コーンスピーカー特有の温かみある音（SPK） と フラットで高品位なスタジオモニター出力（LINE） を瞬時に切り替えられます。

2. 各コントロール部の構造と操作方法

PROG & KIT

音色・ドラムキット切替

  • PROG (音色選択): 左右の ‹ › ボタンで128種類のGM/シンセプリセットを順送り。中央の表示窓をクリックすると、全カテゴリー一覧からダイレクト選択できます。
  • KIT (ドラム選択): 808、909、アコースティック、ジャズ、サイバーなど厳選10キットを切り替えます。
RECORDER & TOOLS

録音・スケール・デモ機能

  • REC / LOOP: 演奏をリアルタイムに劣化なしのWAVで録音。ループ再生しながら重ねて練習できます。
  • ⬇ EXPORT WAV: 録音したテイクを16-bit 44.1kHzのマスターWAVとしてワンクリック保存可能。
  • ♩ CLICK: メトロノーム（テンポ同期）のON/OFF。
  • SCALE & CHORD: 白鍵を弾くだけで指定した調性（ペンタトニック、マイナー等）に自動補正するスケールロックや、ワンフィンガーコード演奏を設定可能。
  • DEMO GROOVES: プロフェッショナルなデモトラックを試聴可能。
OLED & 4 KNOBS

有機EL画面 & リアルタイム・ノブ

  • OLED SCREEN: 現在の音色、BPM、オクターブ、DSP動作状態をリアルタイム表示。クリックすると画面色（シアン/アンバー/グリーン）が変化します。
  • 4つのロータリーノブ: ノブの左側に数値を表示。ノブを上下にドラッグして音色を劇的に変化させます（ダブルクリックでデフォルト値へリセット）。
    • CUTOFF / RESONANCE: フィルターの明るさと鋭さを調整。
    • REVERB / CHORUS: 空間の広がりや音の厚みを調整。
  • MODE SYNTH / ENV: 右端のボタンで「フィルター＆エフェクト」と「ADSRエンベロープ（アタック・ディケイなど）」の操作を切り替えられます。
JOYSTICK & BUTTONS

PITCH / MOD & コントロール

  • PITCH / MOD ジョイスティック: 左右でピッチベンド（±2半音）、上方向でビブラート（モジュレーション）、下方向でフィルターモジュレーションを無段階で付加。指やマウスを離すと中央に戻ります。
  • OCTAVE (- / +): 鍵盤のオクターブを上下に変更（PCキー: Z / X）。
  • FULL LVL: 全てのドラムパッドを最大ベロシティ（127）で鳴らすAKAIスタイル機能。
  • REPEAT: パッドを押し続けるだけで、テンポに合わせた連続連打ビートを自動生成。
  • BANK A / B: パッドを1〜8番から9〜16番へ切り替え。
  • ARP (アルペジエーター): 鍵盤を押さえると分散和音を自動アルペジオ演奏。歯車アイコンで上昇・下降・ランダムや音符の細かさを変更できます。
  • TAP BPM: リズムに合わせてクリックすることで演奏テンポ（BPM）を直感設定。
  • PANIC: 音が鳴り止まなくなった際に全発音を瞬時に遮断。
PADS & KEYBED

ドラムパッド & 25鍵ベロシティ鍵盤

  • 8つのベロシティ対応パッド: タッチやクリック、PCキー 1〜8 でキック・スネア・ハイハットなどを直感演奏。
  • 25鍵フルサイズ・シンセアクション鍵盤: 和音（ポリフォニック）演奏に対応。キーヒント表示でPCキーの位置も一目瞭然です。

4. 初心者向け実践チュートリアル (曲作りの第一歩)

音楽理論の知識がなくても大丈夫です！以下の5つのステップに沿って操作するだけで、プロフェッショナルなトラックが完成します。

STEP 1: テンポとリズムの土台を作る

808ビートとノートリピートでグルーヴを作る

  1. 画面上部中央の KIT をクリックし、04: Electronic 808（または 05: Classic 909）を選択します。
  2. PITCH/MOD右側のボタン群から REPEAT ボタンをONにします。
  3. PCキーの 4（Closed HH）を押し続けてみてください。テンポに合わせて小気味良いハイハットが自動で連打されます！
  4. 左手で 4 をキープしながら、右手でリズムに合わせて 1 (Kick) と 2 (Snare) を交互にポンポンと叩いてみましょう。これだけで現代的なトラップ・ヒップホップのビートが完成します。
STEP 2: 外さないメロディを作る (スマートスケール)

音楽理論不要！ペンタトニック・スケールロック

  1. 上部バーの SCALE: OFF ⚙ をクリックします。
  2. Root Note: C、Scale Mode: Minor Pentatonic（または Major Pentatonic）を選び、「ENABLE SCALE LOCK」にチェックを入れます。
  3. 鍵盤のどのキー（白鍵 A S D F G...）を適当に弾いても、決して不協和音にならず、かっこいいアジアン＆ファンク調のメロディになります！
STEP 3: 音色をきらびやかに変身させる (ノブ調整)

CUTOFF と REVERB で音の表情をつける

  1. PROG を 080: Synth Lead 1 (Square) または 004: Rhodes EP に設定します。
  2. 鍵盤を押さえながら、上の CUTOFF ダイヤルを下にドラッグして「40」あたりまで絞ってみましょう。音がモコモコと暖かくなります。
  3. そこから勢いよく上へドラッグ（「110〜127」）すると、クラブサウンドのようなフィルターオープンの快感が得られます。
  4. 隣の REVERB ダイヤルを「60〜80」まで上げると、まるで大聖堂や大きなホールで演奏しているような美しい残響が加わります。
STEP 4: アルペジエーターで疾走感を出す

指1本〜和音を押さえるだけでフレーズが自動疾走

  1. コントロールボタンの ARP ボタンをONにします（キーボードの V でも可）。
  2. 鍵盤の A と D と G（ド・ミ・ソ）を同時に押し続けてみてください。
  3. 流れるような美しいアルペジオ・メロディがテンポ同期でエンドレスに鳴り響きます。
  4. 左側のジョイスティックを上下に動かすと、フレーズに生き生きとしたビブラートがかかります！
STEP 5: あなたの演奏を録音して作品にする

マスターWAVレコーディング & ループ再生

  1. 上部バーの ● REC をクリックすると、カウントと同時に録音が開始されます。
  2. ステップ1〜4で試したビートやフレーズを自由に演奏しましょう！
  3. もう一度ボタン（STOP）を押して録音を終了します。
  4. ▶ LOOP を押すと、いま演奏したフレーズがそのままBGMとしてループ再生されます。その上にさらに新しいソロを重ねて楽しめます。
  5. 満足のいくテイクが録れたら、⬇ EXPORT WAV をクリック。高音質なWAVファイルがあなたのPCやスマホに即座に保存されます！

5. 上級テクニック & 推奨ハードウェア活用法

1. USB / Bluetooth MIDIキーボードのプラグ＆プレイ

本アプリは Web MIDI API に完全対応しています。
AKAI MPK mini、KORG microKEY、Novation LaunchkeyなどのMIDIキーボードをPCやMac、iPadにUSBケーブル（またはBluetooth）で接続するだけで、設定不要で自動認識されます。
物理鍵盤の打鍵強さ（ベロシティ）やピッチベンドホイール、サステインペダルがそのままダイレクトに反映されます。

2. USER PRESETS（お気に入り設定の保存）

納得のいく音色、リバーブ、カットオフ、アルペジオ設定ができたら、上部バーの 💾 USER PRESETS をクリック。
「USER 1」〜「USER 8」のいずれかのスロットの「SAVE CURRENT」を押すと、ブラウザ内にあなた専用のカスタムセッティングが永続保存され、いつでも瞬時に呼び出すことができます。

3. PWA（プログレッシブWebアプリ）としてのインストール

Chrome、Edge、Safariなどのブラウザメニュー、または右上バーの INSTALL APP ボタンからホーム画面やデスクトップにアプリとしてインストールできます。
インストール後は完全にオフライン状態でも動作し、アドレスバーのない全画面スタンドアロン・シンセサイザーとして低レイテンシーで快適にご利用いただけます。

ワンポイント・アドバイス:
音が重なりすぎてクリアにしたいときは、操作ボタンの PANIC を押すか、各音色の「DECAY / RELEASE」を短めに設定するとタイトで抜けの良いビートを作ることができます。
